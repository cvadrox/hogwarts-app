УСТАНОВКА

1. Распакуйте архив. Загрузите все файлы из папки hogwarts-app в одну папку HTTPS-сайта. Файлы manifest.webmanifest и sw.js должны открываться по URL без авторизации и перенаправления на HTML.
2. Откройте адрес этой папки на телефоне.
3. Android: Chrome → меню → «Установить приложение». Можно воспользоваться кнопкой «Установить на телефон» в меню приложения.
4. iPhone: Safari → «Поделиться» → «На экран Домой». Если есть переключатель «Открывать как веб-приложение», включите его.
5. Запускайте с новой иконки: приложение откроется в отдельном окне без адресной строки. Системная строка состояния телефона может оставаться.

Это устанавливаемое веб-приложение (PWA), не APK/IPA. Его обслуживает движок браузера; обычные вкладки при запуске с иконки не нужны.
Оболочка доступна после первого открытия и без сети. Для AI-истории и генерации картинок интернет необходим.
При смене домена настройки подключения и идентификатор пользователя не переносятся автоматически. Используйте прежний адрес сайта, чтобы сохранить привязку к серверной истории. Не очищайте данные сайта.
Для первого запуска на новом устройстве потребуется подключить webhook n8n. Синхронизация пользователя между устройствами в этой версии не добавлена.
Настройки workflow и БД менять не требуется. Для сайта на новом домене проверьте разрешённый Origin в n8n.
